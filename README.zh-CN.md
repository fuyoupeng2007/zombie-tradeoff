# 打僵尸 · 取舍之战 2.0：死寂天空

左侧拿补给，右侧抗尸潮。现在你可以跳起来射击空中敌人，躲开冲击波，挑选改装，用不同武器处理组合进攻。

## 直接游玩

双击根目录的 **`打僵尸.html`** 打开中文版，`index.html` 打开英文版。将它们与 `game.js`、`styles.css` 保持在同一文件夹。

只想复制一个文件：使用 **`standalone/打僵尸.html`** 或 `standalone/index.html`。这两个文件已经嵌入脚本和样式，可以单独复制、发送、离线打开。

游戏无需安装依赖、构建或联网。也可运行 `node tools/serve.mjs`，访问 <http://127.0.0.1:8000/打僵尸.html>。GitHub Pages 使用根目录 `index.html`；部署时同时包含 `game.js` 和 `styles.css`。

## 操作

| 按键 | 功能 |
| --- | --- |
| A / D、← / → | 左右移动 |
| 空格、W、↑ | 跳跃；获得“空中跃迁”后可再跳一次 |
| Shift | 朝移动方向冲刺；不移动时朝面向方向冲刺 |
| 鼠标移动 | 启用手动瞄准，可以向天空射击 |
| Q / 瞄准按钮 | 切换自动与手动瞄准 |
| 鼠标左键 / J | 强化射击，有独立冷却；普通射击自动进行 |
| 1 / 2 / 3 / 4 | 切换步枪、霰弹枪、穿甲枪、电弧枪 |
| 按住 E | 在地面补给箱附近开启补给箱；开启时停止射击 |
| Esc / 暂停按钮 | 暂停或继续 |
| Enter | 开始或重开 |
| 升级界面 1 / 2 / 3 | 选择对应卡片 |

手机提供移动、跳跃、冲刺、射击和开箱按钮，支持同时按住多个按钮。点击武器栏换枪；手机默认自动瞄准。推荐横屏，竖屏也可操作。切换页面、窗口失去焦点会自动暂停。

## 敌人和应对

| 敌人 | 能力 | 应对 |
| --- | --- | --- |
| 游荡者 | 向玩家追踪移动 | 控制距离 |
| 疾跑者 | 前摇后直线冲刺 | 跳跃或换位 |
| 装甲卫兵 | 正面装甲吸收部分伤害，可破甲 | 穿甲枪、电弧枪、背面命中 |
| 巨力者 | 砸地产生双向冲击波 | 跳过地面波纹 |
| 巨型坦克 | 大体型高血量，残血加速 | 持续输出并保留退路 |
| 喷毒者 | 弧线毒弹、持续数秒的毒池 | 躲弹，跳过毒池 |
| 自爆者 | 接近后倒计时爆炸；击杀爆炸可引发连锁 | 远距离引爆尸群 |
| 飞翼尸 | 盘旋、预警俯冲、升空恢复 | 对空瞄准或电弧枪 |
| 尖啸者 | 为附近敌人加速并召唤援军 | 优先击杀 |
| 跃袭者 | 蓄力扑向预警落点 | 改变移动方向 |
| 缝合暴君 | 冲撞、砸地、召唤飞翼；半血狂暴 | 观察前摇，兼顾地面与天空 |

最早的特殊敌人在第 10 秒解锁，飞行敌人在第 30 秒解锁，后续逐步加入全部类型。进攻阶段每 30 秒变化，后期强化重装、空袭、高速突袭等组合。首次 Boss 在约 180 秒登场，之后每 180 秒可再出现一个；上一只存活时不会叠加。

僵尸强化调整：普通僵尸基础血量由 7 提升至 13，多数特殊僵尸血量约翻倍，坦克由 58 提升至 130，Boss 由 1800 提升至 3200。追击速度普遍增加约 30%～60%，血量随时间增长更快，90 秒后增加额外成长。

45 秒后出现从屏幕外进入的三只协同增援；后期刷新更密集，但敌人总数仍限制在 85。飞翼的俯冲时间根据距离计算，跃袭能够到达其落点；攻击预警保留。喷毒者在 60 秒后一次发射两枚毒弹，毒池持续 7 秒。尖啸者召唤两只援军，并提供更强、持续更久的加速。Boss 在两个阶段分别召唤三只、四只飞翼，冲撞和技能循环也更快。

## 武器、成长与难度

- **步枪：** 稳定远距离输出；强化射击发射三发散射弹。
- **霰弹枪：** 近距离七颗弹丸，适合突围；弹丸射程较短。
- **穿甲枪：** 高速、贯穿多个目标，绕过装甲吸收。
- **电弧枪：** 550 单位有效距离，连锁附近敌人，适合空战与聚集敌群。
- 普通卡提升攻击、攻速、生命或护盾。满血医疗转为护盾；攻速达到实际下限后，后续攻速卡转为伤害增长。护盾最多三层。
- 每 30 秒暂停一次，提供三张不同改装卡；Boss 战期间延后选择。包含二段跳、伤害、攻速、穿透、连锁、暴击、医疗、防护和机动升级。
- 补给箱需要在附近按住 E 约 0.85 秒，开启时无法开火。开箱提升攻击并给予护盾与治疗。
- 清屏支援清除当前屏幕中的普通敌人，对 Boss 造成最大生命 16% 的伤害；不会直接秒杀 Boss。特殊穿甲支援朝当前瞄准方向发射。
- **辅助：** 8 点初始生命、较弱尸潮、危险时救援加速。
- **标准：** 6 点初始生命，战术生存，无自动救援加速。
- **困难：** 5 点初始生命，更高敌人血量、更快移动和更密集刷新。
- 各难度分别保存最高分；浏览器存储不可用时仍可正常游玩。

## 美术与实现

原创 Canvas 2D 末日卡通造型：分部位肢体、头盔与护具、各类型独有轮廓、武器后坐力、起跳与落地尘土、护盾、破甲、自爆连锁和攻击预警。场景包含多层废墟、昏黄太阳、车辆、电线、补给路标、道路裂纹与漂浮余烬。

所有图形和音效均由代码生成，无外部美术、字体、音频或网络请求。高低画质可切换；背景缓存绘制，粒子和实体数量受控，物理以固定 120 Hz 步长更新，子弹采用扫掠碰撞，避免高速穿过目标。

## 开发与验证

运行游戏无需 Node；下列命令仅用于开发：

```sh
node --check game.js
node tools/build-entry.mjs --standalone
node tools/verify.mjs
```

测试使用 Playwright 和无界面 Chromium / Chrome，需要开发环境提供 Playwright。可用 `npm install` 安装开发依赖，再执行 `npx playwright install chromium`；现有 Chrome 可通过 `CHROME_PATH` 指定，已有 Playwright 包可通过 `PLAYWRIGHT_PACKAGE` 指定。测试产物保存在 `qa/`，包括 JSON 报告及桌面、移动端截图。

根目录中英文入口由 `tools/build-entry.mjs` 生成，共用 `game.js` 与 `styles.css`。修改后运行生成脚本以同步独立文件。普通游戏页面不暴露测试接口；只有 URL 带 `?test=1` 时才启用本地自动化检查接口。
